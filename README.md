# Password_Manager
Password Manager
CLI-based interface for managing passwords

-------------------------------------------------

## Changelog/Feature History

### September 05, 2026
* **Authentication**: Added sign-up and sign-in functionality.
* **Account Security**: Implemented maximum attempt lockouts.
* **Data Operations**: Implemented interactive CRUD menu options to add, view, and delete saved website credentials.
* **Security & Lockouts**: Added login attempt limits with a 10-second lockout timer upon repeated failed sign-ins.
  
### September 06, 2026
* **Persistent Storage**: Integrated local file handling (`master.txt` and `vault.txt`) to automatically load and save master accounts and vault credentials.
* **Account Setup**: Added master account creation with password confirmation logic.
